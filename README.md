# Seasons

An original, clean-room seasonal gameplay plugin for Paper 26.2.

This project contains no code, assets, configuration files, or branding copied
from other plugins. It uses only Paper's public Bukkit API.

## Included gameplay

- Per-world spring, summer, fall, and winter state
- Seasonal weather probabilities
- Snow placement and source-water freezing in winter
- Seasonal ice thawing outside winter
- Optional winter crop-growth pause
- Configurable extra natural spawns by season
- Administrative and player information commands

See `COMMANDS.txt` for the command reference.
